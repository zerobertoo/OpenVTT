OpenVTT

An open source, self-hosted virtual tabletop for tabletop RPGs, written from scratch. The game master hosts a world; players join by link.

View on GitHub Run it yourself

What is in it

Maps and scenes

Images or animated video maps, square grid or none, smooth pan and zoom, and a distance ruler in feet, meters or squares.

Map import

Universal VTT (Dungeon Alchemist and others), Foundry-style exports and plain images, with walls, doors, lights and multi-floor maps.

Fog of war and lighting

Players only see what their tokens see, shaped by walls, closed doors and light. Walls stay on the server.

Dice and chat

Rolls like /r 1d20 adv happen on the server. Whispers, GM-only rolls and a persisted history.

Sheets and rules systems

JSON templates with computed fields, editable without code. A generic system and D&D 5e SRD are included; add your own.

Yours to keep

One SQLite file and a folder of assets. Export a whole world as a zip and import it anywhere.

The server is authoritative: every action is checked by role, and hidden tokens, whispers and other players' sheets are never sent to clients that cannot see them.

Run it yourself

OpenVTT needs a small server (WebSocket and SQLite), so it cannot run on static hosting. With Docker:

git clone https://github.com/zerobertoo/OpenVTT.git
cd OpenVTT
docker compose up -d --build

Then open http://localhost:3000. The first account becomes the administrator. From source (Node.js 24+ and pnpm): pnpm install && pnpm start. See the README for backups, reverse proxies and map import.
