# Getting help

OpenVTT is a personal open source project, so support is best effort and there is no response-time promise.

| I want to... | Go to |
|---|---|
| Install or configure OpenVTT | [Getting started](docs/getting-started.md), [Configuration](docs/configuration.md), [Reverse proxy](docs/reverse-proxy.md) |
| Fix something that does not work | [Troubleshooting and FAQ](docs/troubleshooting.md) |
| Learn how to use a feature | [Documentation index](docs/index.md) |
| Ask a question | [Open a "Question" issue](https://github.com/zerobertoo/OpenVTT/issues/new?template=question.yml) |
| Report a bug | [Open a "Bug report" issue](https://github.com/zerobertoo/OpenVTT/issues/new?template=bug_report.yml) |
| Suggest a feature | [Open a "Feature request" issue](https://github.com/zerobertoo/OpenVTT/issues/new?template=feature_request.yml) |
| Report a security problem | [Private vulnerability report](https://github.com/zerobertoo/OpenVTT/security/advisories/new) (see [SECURITY.md](SECURITY.md)). Never in a public issue. |
| Report a conduct problem | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

Before opening an issue, search the existing ones. A good report includes the OpenVTT version or commit, how you run it (Docker or source), your browser, and the steps to reproduce.
